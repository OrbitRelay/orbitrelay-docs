# OrbitRelay Documentation

This repository contains public documentation for released OrbitRelay
components and currently implemented behavior.

Public documentation is limited to verifiable architecture, protocol usage,
Community deployment, client integration, contribution guidance, and released
compatibility information. Internal alternatives, unpublished product work,
commercial implementation detail, and decision drafts are maintained outside
this repository.

## Components

- [`orbitrelay-spec`](https://github.com/orbitrelay/orbitrelay-spec)
- [`orbitrelay-kernel`](https://github.com/orbitrelay/orbitrelay-kernel)
- [`orbitrelay-server`](https://github.com/orbitrelay/orbitrelay-server)
- [`orbitrelay-flutter`](https://github.com/orbitrelay/orbitrelay-flutter)
